# Privacy

Numera collects nothing. There's no server, no account, no analytics, and no tracking of any kind.

## What's stored, and where

Everything — each player's name, grade, level, XP, buddy look and color, and their session history — is saved in one place: your browser's local storage, on the device you're using. It's used only to run the app for you. It is never sent anywhere, because Numera has nowhere to send it: there is no backend.

- **A first name or nickname is all we ask for.** Don't use a full legal name or any other personal information — the app doesn't need it, and it wouldn't go anywhere useful if you did.
- **Nothing leaves the device**, online or offline. Numera makes no network requests to any third party — fonts, code, and every asset ship with the app itself.
- **No accounts, no sign-in, no email.** There's nothing to create and nothing to forget.
- **You control the data.** "Export data" (in Grown-ups) saves a player's history as a JSON file you keep yourself. "Remove" on the profile screen deletes a player and their history from this device for good.
- **Clearing your browser's site data for this page** deletes everything Numera has stored, the same as "Remove" for every player at once.

## Third parties

None. Numera has no ads, no analytics SDKs, no crash reporters, and no embedded trackers.

## Children's privacy

Numera is built for children to use directly, which is exactly why it collects nothing: no name beyond an optional first name or nickname chosen by a grown-up, no age, no email, no location, no device identifiers, and no way for that information to leave the device it's used on.

## Changes

If this ever changes — for example, if a future version adds optional cloud sync — this file will say so before that version ships, and it will describe exactly what's sent and why.
